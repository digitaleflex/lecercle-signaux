# Images à fournir

Dépose ici les images de la page, puis remplace le cadre `[NEED]` correspondant dans `index.html` par une balise `<img>`.

| Fichier conseillé | Section | Contenu |
| --- | --- | --- |
| `mockup-telephone.webp` | S2-S3 | Téléphone avec une alerte de signal, la note vocale et le calculateur |
| `emerson-pourquoi.webp` | S10 | Portrait d'Emerson, lumière naturelle |
| `mockup-cercle.webp` | S13 | Visuel 3D du Cercle Signaux X |
| `mockup-cercle-accelerateurs.webp` | S15 | Visuel 3D « box » du Cercle + 7 accélérateurs |
| `emerson-mentor.webp` | S18 | Photo d'Emerson, ton mentor |
| `temoignage-*.webp` | S19 | Captures ou vignettes des témoignages |

Format conseillé : WebP, moins de 200 Ko par image, pour un chargement rapide sur mobile.

Exemple de remplacement :

```html
<img src="assets/img/emerson-mentor.webp" alt="Emerson, fondateur du Cercle Signaux X" loading="lazy" width="600" height="760">
```
